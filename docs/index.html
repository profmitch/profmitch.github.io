Also More Chemistry

  • Morrison & Boyd Organic Chemistry, 3rd Ed (1973)
    One of the first things I did in mid-1980s between graduation and becoming a grad student was to use the beginning versions fo Microsoft Word to make notes and summaries of the content (text and figures) of the Morrison & Boyd organic chemistry text, what I consider the bible of texts on the teaching and learning of organic chemistry. I had the hardback 1973 edition. I got a lot of it transcribed, not all. I consider it the ultimate reference for undegraduate perhaps even graduate level organic chemistry.

    In the mid-1990s with the advent of the World Wide Web, I used Word to save the DOC file as an HTML file (the markup used to create web documents). Of course Microsoft rendered HTML pages badly, with a lot of MS-specific formatting not part of the recommended specification for these documents. The HTML markup still contains the residue of MS nonstandard formatting which I will make an effort to clean up. If I were editing it today (2026), I would make use of many extensions (scripts) in rendering this text as well.
